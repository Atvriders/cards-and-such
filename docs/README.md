# docs/

Long-form documentation for the cards-and-such project. The short, must-read
docs (project overview, contributing, security, code of conduct) live in the
repo root; this directory holds the deeper material that does not need to be
on the front page.

## Contents

### Game catalogs

Backlog/inspiration lists used while bulking up the registry. These are
historical reference material, not a source of truth — the real game list
is `web/src/games/registry.ts`.

- [`game-catalog.md`](game-catalog.md) — original Phase 2+ backlog (1,188
  entries) generated 2026-04-20.
- [`game-catalog-extended.md`](game-catalog-extended.md) — second-pass
  expansion of the catalog.
- [`game-catalog-volume-3.md`](game-catalog-volume-3.md) — third
  expansion volume.

### Specs and plans

- [`superpowers/specs/`](superpowers/specs/) — design specs (Phase 1
  platform design lives here).
- [`superpowers/plans/`](superpowers/plans/) — multi-step implementation
  plans (platform foundation, single-player games, multiplayer polish).
